# AETH Protocol — Security Policy

## Supported Versions

| Version | Status |
|---------|--------|
| 0.8.x   | ✅ Active |
| < 0.8   | ❌ Not supported |

## Reporting a Vulnerability

**Do NOT open a public GitHub issue for security vulnerabilities.**

### Process

1. Email: `security@aeth.network`
2. Include:
   - Description + impact
   - Steps to reproduce
   - Affected component (network / prover / program)
   - Suggested fix (if any)
3. We respond within **48 hours**
